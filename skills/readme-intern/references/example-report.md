## ❌ Step 6: `make run`

```text
make: *** No rule to make target 'run'.  Stop.
```

The Makefile target is `serve`. After renaming it in the README, round 2 hit a second bug that the
static check could not see:

```text
. .env && python -m weatherdash.server
/bin/sh: 1: .: .env: not found
```

Make runs recipes with `/bin/sh`, which is dash on Debian/Ubuntu. Dash's `.` searches `$PATH`, not
the current directory, so `. .env` only works on the author's shell. Fixed with `. ./.env`.
